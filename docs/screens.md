# Скриншоты лендинга

Сняты 12–13.10.2026 на эмуляторе Pixel 9 Pro XL (1344×2992, 480 dpi) с релизной сборки `oh-my-guide.apk` (HEAD `588c64d`, ветка `dev_12_10_2026_1`).
Статус-бар — SystemUI demo mode (9:41, Wi-Fi, батарея 100%). Геопозиция — Красная площадь (`adb emu geo fix 37.6208 55.7539`).
Каждый экран снят в светлой и тёмной теме приложения (переключатель в шапке).

Сырые PNG лежат в `screens-raw/` (в git не попадают). WebP для сайта собирает `npm run screens`.

## Отрывок для демо озвучки

Первое предложение экскурсии «Храм Василия Блаженного» (модель `openai/gpt-oss-120b`, экскурсия из карточки места):

> Храм Покрова Пресвятой Богородицы на Рву, более известный как Храм Василия Блаженного, построен в 1555—1561 годах по указу Ивана Грозного в знак благодарности за победу в Казанской войне; комплекс состоит из одиннадцати отдельных храмов, соединённых единой основанием‑подклётом.

Дальше в той же экскурсии модель выдумывает факты (Джордж Вашингтон в 1791 году, коронация Николая II в храме, «Брат 2» в 2003-м). Поэтому для демо взято только первое предложение.
